fix-ui

Point at what's wrong. Your coding agent fixes it.

The local fixui daemon. Loopback http only — that is all the extension asks permission for.
The bridge prints this when it starts and writes it to .fix-ui.token in its working directory. It gates the review channel — without it, notes still work but request_review cannot reach this browser.
One origin=/absolute/project/path per line; # starts a comment. Exact origins only. Notes taken on an unmapped origin go to the bridge's own working directory.
Add |a name at the end of a line to label that origin — the agent sees it in list_surfaces and can send a review to exactly that page, which is how two ports of one app stay apart. origin=|a name labels an origin without mapping it to a project.
